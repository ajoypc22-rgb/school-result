# Student Result Portal (Free)

Roll Number দিয়ে সার্চ করা যায় এমন একটি ফ্রি রেজাল্ট পোর্টাল। কোনো ব্যাকএন্ড/সার্ভার লাগে না — শুধু `results.json` ফাইল এডিট করলেই নতুন রেজাল্ট প্রকাশ হয়ে যাবে।

## ফাইল কাঠামো

```
index.html     → মূল পেজ (কখনো এডিট করার দরকার নেই)
style.css      → ডিজাইন (কখনো এডিট করার দরকার নেই)
script.js      → লজিক / GPA হিসাব (কখনো এডিট করার দরকার নেই)
results.json   → ⭐ এই ফাইলটাই শুধু আপনি এডিট করবেন
logo.png       → স্কুলের লোগো (আপনার নিজের লোগো দিয়ে replace করুন)
```

## নতুন রেজাল্ট প্রকাশ করবেন কীভাবে

1. `results.json` ফাইলটি খুলুন (GitHub-এ সরাসরি এডিট করা যায়, Excel-এর দরকার নেই — নিচে Excel → JSON করার উপায়ও দেয়া আছে)।
2. `school` অংশে স্কুলের নাম, ঠিকানা, পরীক্ষার নাম বসান।
3. `students` লিস্টে প্রতিটি শিক্ষার্থীর জন্য একটি অবজেক্ট যোগ করুন:

```json
{
  "roll": "105",
  "name": "ছাত্র/ছাত্রীর নাম",
  "class": "দশম",
  "section": "ক",
  "fatherName": "পিতার নাম",
  "subjects": [
    { "name": "বাংলা", "grade": "A+" },
    { "name": "ইংরেজি", "grade": "A" }
  ]
}
```

4. গ্রেড হিসেবে শুধু এই মানগুলো ব্যবহার করুন: `A+, A, A-, B, C, D, F`
5. কোনো একটি বিষয়ে `F` (ফেল) থাকলে ঐ শিক্ষার্থীর GPA স্বয়ংক্রিয়ভাবে `0.00` হয়ে যাবে এবং স্ট্যাটাস "অনুত্তীর্ণ" দেখাবে।
6. ফাইলটি save করে GitHub-এ commit/push করলেই সাথে সাথে নতুন রেজাল্ট লাইভ হয়ে যাবে। কোনো কোড পরিবর্তনের দরকার নেই।

## Excel থেকে JSON বানাবেন কীভাবে

আপনার স্কুলের নিজস্ব মার্কশিট ফরম্যাটের (`মোট নম্বর` / `প্রাপ্ত নম্বর` / `গ্রেড` কলাম সহ) জন্য একটি রেডি স্ক্রিপ্ট দেয়া আছে — `excel_to_json.py`।

```bash
python3 excel_to_json.py আপনার_মার্কশিট.xlsx results.json
```

এই স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে:
- হেডার সারি থেকে বিষয়ের নাম পড়ে নেয়
- প্রতিটি শিক্ষার্থীর `প্রাপ্ত নম্বর` দেখে আপনার Excel-এর গ্রেড ফর্মুলার সাথে হুবহু মিলিয়ে গ্রেড বসায়
- `results.json` তৈরি করে দেয় — এই ফাইলটাই GitHub-এ আপলোড করলেই নতুন রেজাল্ট লাইভ হয়ে যাবে

**⚠️ গুরুত্বপূর্ণ নোট (আপনার আপলোড করা ফাইল নিয়ে):**
1. আপনার Excel-এ `প্রাপ্ত নম্বর` (obtained marks) কলামগুলো এখনো খালি — তাই এই মুহূর্তে সবার গ্রেড `F` দেখাচ্ছে। Excel-এ প্রকৃত নম্বর বসিয়ে ফাইলটা আবার পাঠালে আমি (অথবা আপনি নিজে স্ক্রিপ্ট চালিয়ে) সঠিক রেজাল্ট বসিয়ে দেব।
2. আপনার শিটে কোনো **Roll Number** কলাম নেই — তাই আমি সাময়িকভাবে তালিকার ক্রম অনুযায়ী ১, ২, ৩... করে Roll বসিয়েছি। আপনার কাছে প্রকৃত Roll Number থাকলে জানালে সেগুলো বসিয়ে দেব, অথবা Excel-এ একটি "Roll" কলাম যোগ করে পাঠালে স্ক্রিপ্টে সেটাও যোগ করে দেয়া যাবে।
3. School-এর নাম ও লোগো এখনো ডেমো ডেটা (`আদর্শ উচ্চ বিদ্যালয়`) — আপনার প্রকৃত স্কুলের নাম ও লোগো জানালে বসিয়ে দেব।

ভবিষ্যতে চাইলে এই কনভার্সন প্রক্রিয়াটি আরও সহজ করার জন্য একটি Admin Panel (Phase-2) বানানো যাবে, যেখানে সরাসরি ব্রাউজারে Excel আপলোড করলেই `results.json` অটো তৈরি হয়ে যাবে (তখন Terminal/Python লাগবে না)।

## ফ্রিতে GitHub Pages-এ হোস্ট করবেন কীভাবে

1. [github.com](https://github.com)-এ একটি নতুন public repository তৈরি করুন (যেমন: `school-result`)।
2. এই ৫টি ফাইল (`index.html`, `style.css`, `script.js`, `results.json`, `logo.png`) সেই repository-তে আপলোড করুন।
3. Repository-এর **Settings → Pages** এ যান।
4. **Branch: main**, **Folder: / (root)** সিলেক্ট করে **Save** করুন।
5. কিছুক্ষণ পর একটি লিংক পাবেন — যেমন: `https://your-username.github.io/school-result/`
6. এই লিংকটাই আপনার স্থায়ী, ফ্রি রেজাল্ট পোর্টাল লিংক।
